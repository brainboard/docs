{% hint style="info" %}
Press <mark style="color:$primary;">**⌘ / CTRL + K**</mark> to open the command centre. Type the name of any feature, and <mark style="color:$primary;">**Brainboard**</mark> takes you there
{% endhint %}

{% hint style="info" %}
To open the shortcut modal, press <mark style="color:$primary;">**`?`**</mark>
{% endhint %}
